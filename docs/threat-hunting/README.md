# Threat Hunting

Hypotheses, data sources, and detection ideas.

## Objective

- Identify suspicious or unauthorized patterns and behaviors.
- Bridge intelligence and incident response.
- Track trends over time.

## Method

- Phishing analysis and attack-family clustering.
- AV logs, proxy logs, and firewall logs.
- MITRE ATT&CK and DeTT&CT mapping.
- IoC monitoring.
- Advanced review through reverse engineering when needed.
